# Shule360

Shule360 is a web application under development. The repository currently contains an early Next.js scaffold; product features and setup requirements will be documented here as they are implemented.

## Technology

- Next.js 16 with the App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Prisma
- Clerk and NextAuth packages are included in the project dependencies

## Getting started

### Prerequisites

- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Next.js development server |
| `npm run build` | Build the application for production |
| `npm run start` | Start the production server |
| `npm run lint` | Run ESLint |

## Project status

The application is at an early stage. The home page is currently a placeholder, and product workflows, authentication, database configuration, and deployment instructions have not yet been documented.
